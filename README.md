# Химия вокруг нас

Веб-приложение из двух страниц на тему «Периодическая таблица химических элементов Д. И. Менделеева».

## Структура проекта

1.   `index.html` — Страница 1. Главная страница с изображением периодической таблицы.
2.  `tablica_mendeleeva.html` — Страница 2. Карточки 10 выбранных химических элементов (название, символ, атомный номер, свойства и применение).
3.  `style.css` — Общий файл стилей для обеих страниц (отвечает за внешний вид меню, карточек и фона).
4.   `maxresdefault.jpg` — Изображение периодической таблицы.
5.   `PLAN.md` — План обновления версий от v1.0 до v1.1.

## Инструкция запуска

1. Скачайте все файлы проекта в одну папку.
2. Откройте файл `index.html` в любом браузере.
3. Переключайтесь между страницами с помощью верхнего меню.

## Источники материалов

*   Изображение таблицы: `maxresdefault.jpg` (источник: скриншот из интернета).
*   Данные о свойствах элементов: базовый курс школьной программы по химии.
